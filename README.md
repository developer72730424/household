# シンプル家計簿

アカウント不要・広告なし・データは端末の中だけに保存する、日本語の家計簿アプリです（Expo / React Native）。

## 機能
- 支出・収入の記録（編集・長押しで削除）、カテゴリ、よく使う項目のテンプレート
- 月ごとの収支と、月間予算の進捗バー（毎月共通の予算と、その月だけの予算）
- 先月との支出の比較、カテゴリ別の予算（使いすぎに色でお知らせ）
- 入力のリマインド通知（毎日、好きな時刻に）
- 固定費の自動登録（家賃・サブスクなどの支出、給与などの収入。発生日に履歴へ追加）
- 収支統計（月別推移・内訳）、検索・フィルター
- バックアップ（JSON）と復元、CSV / テキストレポートの書き出し。しばらくバックアップしていないとホームで案内
- ダークモード

## 動かし方
```bash
npm install
npm start        # Expo Go などで確認
npm test         # 単体テスト
npx tsc --noEmit # 型チェック
npm run lint
```
iOS のネイティブビルドや構成の詳細は [.github/copilot-instructions.md](.github/copilot-instructions.md) を参照してください。

## データについて
データは端末内にだけ保存されます。機種変更や故障に備えて、「データ管理」からバックアップを保存してください。
