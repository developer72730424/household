# リリース手順とストア申請メモ

## 1. 事前チェック（毎回）
```bash
npx tsc --noEmit        # 型チェック
npm run lint            # 警告ゼロ
npm test                # 単体テスト
npx expo-doctor         # 18/18 通ること
```
- `app.json` の `version` を上げる（ビルド番号は EAS が `appVersionSource: remote` で自動採番）。
- アイコン `assets/images/app-icon.png` は **1024×1024・透明なし**（App Store の要件）。

## 2. ビルドと申請（EAS）
```bash
npx eas-cli login                      # 自分のアカウントで一度だけ
npx eas-cli init                       # projectId を、使うアカウントのものに更新（初回のみ）
npx eas-cli build --platform ios --profile production
npx eas-cli submit --platform ios --latest
```
- 注意: `app.json` の `extra.eas.projectId` は、以前のアカウント（sinmouri14）のもの。**別のアカウントでビルドする場合は `eas init` で作り直す**。
- Apple Developer Program への加入（年額）と、App Store Connect でのアプリ登録（バンドルID `com.sinmouri14.household`）が必要。
- Xcode 27 向けの調整は `plugins/with-xcode27-fixes.js`（EAS のクラウドビルドでも prebuild 時に適用される）。

## 3. 実機で確認してから出すもの（シミュレーターでは確かめられない）
- [ ] リマインド通知が、設定した時刻に実際に届く
- [ ] レシート写真をカメラで撮影して添付できる
- [ ] Face ID でのロック解除（実機の Face ID / Touch ID）
- [ ] 古いバージョンのデータが入った端末へ上書きインストールして、データが移行されて残る
- [ ] iCloud Drive へのバックアップ保存と、別端末での復元
- [ ] Android（戻るボタン、キーボード、通知、カメラ）。Android も出す場合

## 4. App Store Connect に入れる内容

### アプリ名・サブタイトル（案）
- 名前: シンプル家計簿
- サブタイトル: 登録不要・広告なしの家計簿

### 説明文（案）
> アカウント登録も広告もない、シンプルな家計簿アプリです。データはすべてお使いの端末の中だけに保存され、外部に送信されることはありません。
>
> ■ かんたんな記録
> 支出・収入をすばやく入力。よく使う項目はテンプレートに登録できます。メモ、支払い方法、レシート写真も残せます。
>
> ■ 続けやすい工夫
> 家賃や給与などの固定費は毎月自動で記録。毎日のリマインド通知で記録の習慣づけをサポートします。
>
> ■ 使いすぎに気づく
> 月ごとの予算とカテゴリ別の予算を設定でき、ホームで進み具合を確認できます。先月との比較も一目でわかります。
>
> ■ 見やすい集計
> 月・年ごとの収支、カテゴリ別の内訳、月ごとの推移をグラフで表示します。
>
> ■ 安心して使える
> Face ID / パスコードでアプリをロックできます。バックアップをファイルに保存して、機種変更時に復元できます。

### キーワード（案・100文字以内）
`家計簿,収支,支出,収入,予算,節約,固定費,レシート,貯金,シンプル,無料,広告なし`

### カテゴリ
- プライマリ: ファイナンス

### 年齢制限
- 4+（暴力・成人向け内容なし）

### App のプライバシー（栄養成分表示）
- **データの収集: なし**（「データを収集しない」を選択）
  - アプリは外部と通信しません（ネットワーク通信のコードなし）。広告・解析 SDK も使っていません。
  - 入力されたデータはすべて端末内（アプリ専用の領域）にのみ保存されます。
- 暗号化: 標準的な暗号化のみ使用（`ITSAppUsesNonExemptEncryption: false` 設定済み）
- プライバシーポリシーの URL: **App Store の申請には URL が必要**。下の雛形を、公開できる場所（GitHub Pages など）に置く。

### 審査用のメモ（Review Notes）
> 登録・ログイン不要のアプリです。すべてのデータは端末内に保存され、通信は行いません。
> 通知（リマインド）、カメラ・写真ライブラリ（レシート添付）、Face ID（アプリのロック）は、いずれも利用者が機能を有効にしたときに許可を求めます。

### 権限の文言（`app.json` に設定済み）
- Face ID: 家計簿のロックを解除するために Face ID を使用します。
- 写真ライブラリ: レシートの写真を選んで記録に添付するために、写真ライブラリへアクセスします。
- カメラ: レシートを撮影して記録に添付するために、カメラを使用します。

### スクリーンショット
- iPhone 6.9インチ（iPhone 16 Pro Max 相当）と 6.5インチが必要。
- 掲載候補: ホーム（収支・予算）、支出入力、年間の集計、カテゴリ別予算、ダークモード。
